# Recurring work, without autonomous applications

The original personal workflow included recurring job-information processing and a weekday 08:00 briefing. The published code **does not install a schedule**. `build_brief` accepts a chosen date and processed synthetic records, yielding high-priority suggestions, nearby deadlines, review-needed items, and a sync-health count. This keeps the example reproducible and credential-free.

Operational learning from the real workflow was to move away from broad job-pool expansion toward targeted role processing and higher-value reminders. Any real schedule, source access, and external write would need owner approval and a separate private integration. Nothing in this repository submits applications.
