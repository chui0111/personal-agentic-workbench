# Privacy boundary

All sample companies, descriptions, dates, and job URLs are fictional. `example.com` URLs are placeholders. The project includes no original recruiting records, résumé, browser profile, screenshots, authentication state, Feishu IDs, or personal schedules. The default demo stores output only in a temporary directory.

Before publication, rerun a secret and tracked-file audit. Do not import private source data into this repository. `.env` and demo outputs are ignored; `.env.example` contains no values. The local mock sink deliberately avoids live service endpoints.
