# Privacy boundary

All sample companies, descriptions, dates, and job URLs are fictional. `example.com` and `example.test` URLs are placeholders. The project includes no original recruiting records, résumé, browser profile, screenshots, authentication state, Feishu IDs, or private schedule configuration. The default demo stores output only in a temporary directory.

Private source data must not be imported into this repository. `.env` and demo outputs are ignored; `.env.example` contains no values. The local mock sink deliberately avoids live service endpoints.

**Privacy boundary:** The recovered evidence ZIP remains outside this repository. Real Feishu URLs, Base/Table/View IDs, credentials, browser profiles, production recruitment records, and private application history are not included. Production access requires user-owned authorization outside the public repository.

**Intellectual-property boundary:** The historical collection code and later Node/Playwright reconstruction contain commercially valuable workflow IP and are intentionally excluded. The missing implementation is a deliberate publication boundary, not an incomplete copy or a dependency needed by the public Python demo.
