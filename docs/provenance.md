# Provenance

The real personal recruitment workflow spanned multiple devices and tools. The original Playwright web-content crawler was created and run on another device with Codex assistance. Its results were transferred to this machine and used downstream, but the original crawler source is not present in this workspace. The local source export contains 7,155 indexed records; this is **not** evidence of 7,155 Playwright page visits.

This public repository is newly written, portfolio-safe reconstruction informed by transferred output evidence, verified downstream behavior (validation, exact deduplication, checkpoint/retry, human review, and Feishu sync/read-back), and the owner's account of the original browser workflow. It is not the byte-for-byte original source. The transferred material does not identify the exact original 14-field extraction schema. The public collector therefore uses only six small fields in a synthetic fixture. Recovering the original source or a definitive original output schema would be required before claiming exact 14-field parity.

No third-party repository code was copied. Original files were inspected read-only and excluded from the public repository.
